# Imágenes de productos

Aquí van las imágenes reales de productos para la demo de Innova La Serena.

## Nombres requeridos

Sube manualmente imágenes con estos nombres:

- `producto-1.jpg`
- `producto-2.jpg`

- `producto-12.jpg`

## Recomendaciones de formato

- Usar imágenes cuadradas o verticales.
- Tamaño sugerido: `1080x1080` o similar.
- Mantener buena iluminación y enfoque del producto.

## Relación con productos

Para cambiar qué imagen usa cada producto, edita el campo `image` en:

- `src/data/products.ts`
